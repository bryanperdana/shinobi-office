Aturan perilaku · Behaviour rules

Status real selalu menang. Hanya agent berstatus Idle yang boleh jalan-jalan. Berpikir / mengetik / approval / error / offline → agent kembali ke meja; yang urgent pakai shunshin (asap) < 0,3 dtk.
Aktivitas idle. Minum teh, baca gulungan di rak skill, lihat papan misi, lihat desa dari jendela, latihan di boneka kayu, jalan-jalan.
Sparring ninja. Dua agent idle ke arena: salam → kuda-kuda → pukul/tangkis, tendangan, lompat, lempar shuriken (percikan) → salam. 15–25 dtk, maks 1 arena, cooldown per agent.
Papan nama selalu jujur. “Idle · sparring” — aktivitas visual selalu ditulis di belakang status real, tidak pernah menggantikannya.
Genin. Subagent keluar dari pintu Academy, berjalan (pathfinding, tidak tembus meja) ke samping meja induk, poof saat selesai.
Ringan. Render berhenti saat halaman tidak terlihat; reduced-motion = pose statis; tanpa aset eksternal.
